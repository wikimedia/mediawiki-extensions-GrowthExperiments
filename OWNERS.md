# Code ownership for GrowthExperiments

Basically all code in this Repository is owned by the Growth team. However, for some short experiments,
there might be some code that is owned by another team. This file exists in order to make that explicit
and clearly state that ownership. Any code not mentioned here should be assumed to be owned by the
Growth team.
